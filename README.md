# 🐍 Python Data Science

Repositório dedicado aos meus estudos de **Ciência de Dados com Python**. Aqui reúno notebooks, exercícios e experimentos feitos enquanto aprendo a manipular, analisar e explorar dados usando as principais bibliotecas do ecossistema Python.

> ⚠️ Este projeto tem fins **exclusivamente educacionais**. O objetivo não é produzir uma aplicação ou biblioteca, mas sim praticar e consolidar conceitos de análise de dados.

## 🎯 Objetivo

Praticar e documentar meu aprendizado em:

- Leitura e manipulação de dados com **Pandas**
- Exploração e limpeza de datasets
- Análise exploratória de dados (EDA)
- Estatística descritiva aplicada
- Visualização de dados
- Boas práticas ao trabalhar com Jupyter Notebooks

## 🛠️ Tecnologias

- [Python](https://www.python.org/)
- [Jupyter Notebook](https://jupyter.org/)
- [Pandas](https://pandas.pydata.org/)

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/python_date_science.git
   cd python_date_science
   ```

2. Crie um ambiente virtual (opcional, mas recomendado):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   ```

3. Instale as dependências:
   ```bash
   pip install pandas jupyter
   ```

4. Inicie o Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

5. Abra o arquivo `Untitled.ipynb` e explore os estudos.
